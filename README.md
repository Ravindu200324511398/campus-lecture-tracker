# Campus Lecture & Attendance Tracker PRO v4 🎓

A modern, high-contrast, feature-rich Academic Attendance & GPA Management System for university students.

## 🚀 Features
- 📊 **Attendance Performance Ring & Bunk Calculator**: Automatically calculates safe skips or required upcoming classes to maintain target attendance percentage (80%).
- 🎓 **Semester Curricula Presets**: Built-in 8-semester (Level 1 to Level 4) curricula for **AI, IT, ITM, Computer Science, Software Engineering, and Data Science**.
- 🎯 **What-If Goal Simulator**: Test hypothetical attendance scenarios and foresee their impact on your target percentage and GPA.
- 🏆 **Academic Streaks & Badges**: Earn achievements like Bunk Proof, GPA Titan, Iron Scholar, and Note Master.
- 📱 **Mobile Responsive Navigation**: Features a slide-out drawer menu matching modern mobile app standards.
- 🎨 **Multi-Theme Support**: Cyberpunk Dark 🌌, Midnight Blue 🌙, and Perfect High-Contrast Light Academic Mode ☀️.
- 📱 **SweetAlert2 Integration**: Premium dark-styled confirmation dialogues and alert popups.
- 📦 **Data Portability**: Backup/Restore JSON state, Export CSV performance reports.
- ↺ **Full Undo/Redo Engine**: Revert and reapply changes with keyboard shortcuts (`Cmd+Z` / `Cmd+Shift+Z`).

## 💻 Tech Stack
- **React 18**
- **Lucide React Icons**
- **SweetAlert2**
- **Vite**

## 🛠️ Setup & Local Run

```bash
# Clone the repository
git clone https://github.com/Ravindu200324511398/campus-lecture-tracker.git

# Navigate to project
cd campus-lecture-tracker

# Install dependencies
npm install

# Start development server
npm run dev
```
